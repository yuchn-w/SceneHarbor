# 分享 SceneHarbor

先讓使用者清楚知道是否適合自己的 Mac、去哪裡下載、第一次如何開啟，以及遇到問題如何回報。

## 可用於發布的介紹文字

SceneHarbor 是免費開源的 macOS 動態桌布工具，支援本機影片、相容的 Wallpaper Engine 場景與網頁桌布，可依顯示器設定播放與排程。可先免登入瀏覽 Steam 公開工坊，下載則需要 Steam 登入與相應存取權。

提供省資源模式及 App 內更新。需要 Apple Silicon Mac 與 macOS 26 以上，目前為未經 Apple 公證的公開預覽版，首次開啟可能需要在系統設定允許執行。

下載與安裝說明：https://github.com/yuchn-w/SceneHarbor
問題回報：https://github.com/yuchn-w/SceneHarbor/issues

## 發布素材與順序

1. 用自己有權分享的素材錄製短片：下載／拖入 Applications、首次開啟、免登入搜尋、本機影片套用、切換效能模式、檢查更新。
2. 下載頁最前面保留 DMG 連結、系統需求與未公證說明。
3. 公開代表性場景的實測條件與結果，不宣稱所有作品固定低耗用或零 bug。
4. 先邀請少量使用者回報安裝和播放問題，修正後再擴大分享至影片或 macOS 社群。避免洗版、買 Star 或假下載。
5. 追蹤 Release 附件下載、問題回報與安裝成功的自願回饋。下載次數會包含維護者、重複下載與機器流量，不能當成活躍使用者人數。

這份文字可由維護者自行分享；專案不會代使用者向社群發文，也不蒐集安裝者清單。
